# Задачи агенту: один PR = один контракт

Общие правила для каждого PR (вставлять в промпт целиком):

> Работаешь в репозитории Ostrovsky42/GroovePuter. Один PR закрывает ровно один контракт ниже. Существующие recipe/variant ID не переназначать, новые только append-only. Golden-тесты и frozen corpus (TSV-базлайны) не перегенерировать без отдельного обоснования в описании PR. Бюджет памяти Cardputer ADV не превышать — приложи цифры сборки до/после. Не трогать UNDO/quantized commit, если контракт этого не требует. В описании PR: что сделано, как проверено, что НЕ сделано.

## PR-1. gen_probe выдаёт takes.jsonl

**Контракт:** `gen_probe --emit-takes-jsonl <out> --recipes <id,...> --takes 8 --phrase-bars 4 --seed <n>` пишет файл по `docs/CONTRACT.md` (genre-lab).

**Сделать:**
- Найти в коде маппинг голосов на роли kick/snare/hat/ohat/bass и зафиксировать таблицей в CONTRACT.md.
- Дубль k = k-е последовательное нажатие G от стартового seed, ровно как на устройстве.
- `pos = step + offset` — с реальным свингом/микротаймингом, который сыграет секвенсор.

**Приёмка:**
- `python -m gplab validate --takes out.jsonl ...` разбирает файл без ошибок.
- Двойной запуск с одним seed → побайтно одинаковый файл (новый host-тест).
- Никаких изменений в генерации — только наблюдение.
