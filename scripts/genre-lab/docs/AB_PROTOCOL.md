# Слепой A/B без музыкального образования

Оба теста спрашивают то, на что отвечает любой слушатель: «одинаковое или разное?» и «что нравится больше?». Термины не нужны.

## Подготовка звука

SEQTRAK играет то, что шлёт GroovePuter, поэтому записываем **выход SEQTRAK**, а не рендер прошивки:
- 8 дублей на вариант, по 16 тактов, одинаковый BPM и громкость, один SEQTRAK-пресет на вариант.
- Файлы называть `<variant>__<take>.wav`, например `house.deep__3.wav`.
- Для теста предпочтения — те же варианты из **текущего** билда в отдельную папку.

## ABX: различимы ли варианты на слух

```bash
python -m gplab ab-plan --mode abx --items rec/new --out ab/abx1 --trials 16
```

В каждой папке `trial_NNN`: A, B, X. Вопрос: X — это A или B? Ответ пишешь в `answers.csv`.

Порог: при 16 попытках на пару нужно **≥ 12 правильных** (односторонний биномиальный тест, p < 0.05). Инструмент печатает это число при создании плана.

## Предпочтение: новый генератор против текущего

```bash
python -m gplab ab-plan --mode pref --items rec/new --baseline rec/old --out ab/pref1 --trials 12
```

В каждой папке 1 и 2, порядок случайный. Ответ: что нравится больше. Порог: **≥ 9 из 12** на вариант.

## Подсчёт

```bash
python -m gplab ab-score --plan ab/abx1
```

## Правила слепоты (один человек)

- Не открывать `_key/` до подсчёта. Лучше скопировать трайалы на телефон без `_key`.
- Слушать в одном месте и на одной громкости. Не больше 20 трайалов за раз, потом перерыв.
- Ответы не менять задним числом.
- Если рядом есть кто-то ещё — пусть он раскладывает файлы, а ты только слушаешь.

## Как читать результат

| результат | значит |
|---|---|
| ABX значим, предпочтение ≥ baseline | вариант готов |
| ABX значим, предпочтение хуже | различимо, но звучит хуже: правим генератор, не метрики |
| ABX не значим, метрики PASS | разница есть в данных, но не слышна — профили слишком близки или тембр SEQTRAK её съедает |
| метрики FAIL | до A/B не доходим |
