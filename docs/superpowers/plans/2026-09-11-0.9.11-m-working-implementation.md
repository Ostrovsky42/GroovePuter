# GroovePuter 0.9.11 M-WORKING Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to execute this plan task-by-task. Preserve RED evidence and verification checkpoints.

**Goal:** Implement the approved M-WORKING architecture so Pattern and Melody edits operate on an ephemeral, lossless WORKING candidate while ACCEPTED canonical material remains unchanged, with no Cardputer static-DRAM growth.

**Architecture:** Reuse the already-paid per-voice `currentPhrase_` footprint as an untagged `WorkingMaterialStorage` holding either a lossless `SynthPattern` or a `RuntimeSynthEventBuffer`. Existing `ActiveMaterial.kind` / sequenced-source authority determines which representation is active; no second representation tag or dirty bit is introduced. Pattern runtime is a projection of Working Pattern. Melody playback continues to consume the Working Melody buffer. Undo/Redo mutates WORKING only. DISCARD reconstructs WORKING from ACCEPTED. Pattern→Melody conversion occurs inside WORKING and is not acceptance.

**Tech Stack:** C++17, SDL host harness, `MiniAcid`, `RuntimePatternEventBank`, `RuntimePhraseEdit`, `UndoOwner`, A2 `MaterialAddress` / `MaterialResolution` / `MaterialVersionToken`, GitHub Actions, Arduino/Cardputer ADV build, ELF DRAM gate.

**Spec:** `docs/superpowers/specs/2026-09-11-0.9.11-m-working-design.md`

### 2.2 Implement an untagged union-like owner

Target API:

```cpp
namespace GroovePuterMaterial {

class WorkingMaterialStorage {
 public:
  WorkingMaterialStorage() { storeMelody({}); }

  void storePattern(const SynthPattern& value) {
    new (&payload_.pattern) SynthPattern(value);
  }
  void storeMelody(const PhraseRuntime::RuntimeSynthEventBuffer& value) {
    new (&payload_.melody) PhraseRuntime::RuntimeSynthEventBuffer(value);
  }

  SynthPattern& pattern() { return payload_.pattern; }
  const SynthPattern& pattern() const { return payload_.pattern; }
  PhraseRuntime::RuntimeSynthEventBuffer& melody() { return payload_.melody; }
  const PhraseRuntime::RuntimeSynthEventBuffer& melody() const {
    return payload_.melody;
  }

 private:
  union Payload {
    SynthPattern pattern;
    PhraseRuntime::RuntimeSynthEventBuffer melody;
    Payload() {}
    ~Payload() {}
  } payload_;
};

static_assert(sizeof(WorkingMaterialStorage) <=
              sizeof(PhraseRuntime::RuntimeSynthEventBuffer));

}  // namespace GroovePuterMaterial
```

Use proper placement lifetime handling for the actual compiler. If the union form is rejected, `std::aligned_storage` is acceptable only with the same size bound and no tag/heap allocation.
