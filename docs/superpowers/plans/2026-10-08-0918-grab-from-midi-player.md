# GRAB: участок MIDI-файла → рабочая мелодия (план)

Статус: план, код не начат. Направление 1 из обсуждения 2026-10-08
(«MIDI-файл как рудник материала»). Владелец выбрал его вместе с кривой
энергии (`2026-10-08-0918-energy-curve.md`).

## Зачем

Сейчас плеер звучит, но ничего не отдаёт проекту. Понравившийся рифф можно
только переиграть руками. GRAB превращает услышанное в материал одним жестом:
зациклил A–B (`f981b7b6`), выбрал дорожку (HUB MIDI, `479931cd`), нажал —
мелодия в голосе A/B, дальше её можно править, генерировать вокруг и
сохранять в слот.

## Связь с планом импорта

`miniacid/docs/superpowers/plans/2026-10-03-midi-workspace-import.md`
(не закоммичен в основном дереве) описывает полный импорт файла в слоты и
Song с транзакцией, журналом и восстановлением. GRAB — тонкий срез, который:

- **переиспользует** его Task 2 (пары Note On/Off, FIFO повторов,
  округление, обрезка нот на краях среза, лимит 128 событий, `validate`);
- **не делает** Task 3 (транзакции, manifest, rollback): пишет только в
  рабочий буфер мелодии через существующий путь с одним Undo, как G в
  режиме MELODY (`SynthSequencerPage::generateMelodyFor`,
  `commitRuntimePhraseEditWithUndo`). На SD ничего не пишется; сохранение в
  слот — штатный путь Melody slots.

Projection-код пишется сразу как `src/audio/midi_import_projection.{h,cpp}`
из плана импорта, чтобы полный импорт потом его унаследовал, а не
дублировал.

## Контракт первого среза

- **Источник:** загруженный в плеер файл; участок = текущий цикл A–B, а без
  цикла — 1/2/4/8 тактов от текущего такта (LENGTH из GEN); одна дорожка =
  выбранная в HUB MIDI / плеере.
- **Цель:** рабочая мелодия голоса из GEN TARGET (A/B); длина мелодии =
  длина участка, округлённая вверх до 1/2/4/8 тактов.
- **Ноты:** исходные позиции и длительности (subtick), velocity как есть.
  Аккорды сохраняются, если мелодия их держит (chord playback уже есть);
  иначе политика LAST NOTE из плана импорта. Ноты через A обрезаются,
  через B — укорачиваются. Больше 128 событий — отказ с причиной, без
  тихого усечения.
- **Высота:** как в файле. Опция «в тональность проекта» — второй шаг.
- **Undo:** одно нажатие Ctrl+Z возвращает прежнюю мелодию.
- **Отчёт (toast):** `GRAB T03 BARS 5-8: 23 NOTES` или причина отказа.

## Где выполняется чтение (MIDI-путь)

Файл открыт одним `File` в задаче плеера; читать его из UI-задачи нельзя
(SD и курсор потока общие). Поэтому:

1. UI ставит команду `GrabRegion{track, startTick, endTick}` в очередь плеера.
2. Задача плеера: только если состояние Paused/Stopped (при игре — отказ
   «PAUSE TO GRAB»; позже можно разрешить), репозиционирует поток на
   startTick (тот же rescan, что seek назад), собирает ноты дорожки до
   endTick в буфер `RuntimeSynthEventBuffer` (heap, nothrow, ~1.3 КБ),
   затем возвращает поток на `pausedTick_`.
3. Результат публикуется в однослотовый mailbox (generation + готовность).
4. UI забирает буфер и делает коммит в рабочую мелодию через
   `commitRuntimePhraseEditWithUndo` под audio guard.

Инварианты skill `midi-path` не задеваются: очередь событий плеер→диспетчер
не используется, ничего не отправляется на провод, работа ограничена
длиной участка. DRAM: один временный буфер на время операции; проверить
`freeInt`/`largest` в `[SMF-INIT]`.

## Задачи

1. **Projection (host, TDD).** `midi_import_projection`: из потока событий
   одной дорожки и окна [startTick, endTick) с PPQN файла → Melody buffer.
   Тесты из Task 2 плана импорта, только Melody-часть (четверть при PPQN=480
   → 96 ticks / 1536 subticks; FIFO; обрезка; 129 событий → отказ).
2. **Команда плеера.** `ISmfPlayerService::grabRegion(...)` + mailbox;
   реализация в `cardputer_smf_player`; host-тест на mailbox/поколение.
3. **UI.** Клавиша на странице плеера (кандидат `G` — занят «follow» в
   SEQ MASTER; выбрать свободную, например `Y`), подтверждение цели
   `GRAB T03 -> MELODY A?`, toast-отчёт; переход в MELODY после успеха.
4. **Проверка на устройстве:** Nightcall bars 8–11 track 4 → MELODY A,
   сравнить на слух; LoFi `calm_melancholic` piano interlude.

## Второй шаг (не в первом срезе)

- Транспонирование в тональность проекта (ступени, а не полутоны).
- **GRAB GROOVE:** из участка барабанов/баса — средний сдвиг по шагам
  (LoFi: бас +39 мс, барабаны +24 мс) и профиль velocity → шаблон FEEL.
  Нужно сперва проверить, что модель FEEL умеет хранить сдвиг по шагам.
- GRAB в STEPS (проекция на сетку 1/16 с `timing`) — из плана импорта.
