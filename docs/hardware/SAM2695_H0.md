# SAM2695 H0 — Hardware UART Smoke Test

Branch: `agent/20260902-05-0.9.10-sam2695-midi-integration`

Base: `0a2a6211ef00dcf2214dfd4704b6c34b424b1c9d` (`dev_0.9.9`)

## Scope

This checkpoint proves only the physical Cardputer ADV ↔ M5Stack Unit MIDI (SAM2695) UART path and audible synth output.

No production musical semantics, GENRE/RECIPE/GF2 policy, routing ownership, or USB/SEQTRAK behavior is changed by H0.

## Physical connection

Connect Cardputer ADV to M5Stack Unit MIDI through the HY2.0-4P/Grove cable.

- Cardputer GPIO1: UART RX
- Cardputer GPIO2: UART TX
- UART: 31250 baud, 8N1
- Unit MIDI switch: `SEPARATE`
- Audio: use the Unit MIDI 3.5 mm AUDIO output, not a MIDI connector

## Proof sequence

The first hardware proof is intentionally minimal:

1. Initialize a hardware UART at 31250 baud with RX=GPIO1 and TX=GPIO2.
2. Send MIDI Note On on channel 1: `0x90 0x3C 0x64`.
3. Hold for about 750 ms.
4. Send MIDI Note Off on channel 1: `0x80 0x3C 0x00`.
5. Repeat every ~2 seconds during the smoke test.

Expected result: middle C is audible from the SAM2695 audio output on every cycle.

## Pass criteria

H0 PASS requires all of the following:

- Cardputer ADV boots without brownout/reset loop.
- SAM2695 Unit powers from the Cardputer connection.
- Repeated Note On / Note Off sequence produces a stable audible note.
- No stuck note remains after Note Off.
- Repeating the test for at least 30 seconds does not reset either device.

## Result — PASS (2026-09-02)

## Explicitly not proven by H0

- Production `MusicalEvent` routing
- SAM2695 sink ownership
- MIDI IN
- external DIN MIDI OUT
- Program Change / GM voice selection
- drums mapping
- INTERNAL / SAM / BOTH output policy
- transport clock
- hardware latency/jitter bounds

Those belong to later checkpoints after H0 is accepted.
